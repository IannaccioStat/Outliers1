# Outliers1

Official repository for the paper:  
**"Nonparametric framework for the definition, adaptive detection and probabilistic interpretation of outliers"**

This repository contains all the functions needed to exactly replicate every result, table and figure from the paper and its supplementary material.

## What's Inside

* **`ODKm_pub`**: The primary file containing all core statistical routines and functions.
* **8 Replication Scripts**: Individual scripts designed to reproduce every single figure in the paper exactly as shown.
